# CS 772 - Transliteration Analysis

We would do transliteration on hindi to english on word level. These techniques could be used on anny language pair. We would use three techniques and compare them. the three techniques are:
- LSTM
- Transformer
- LLM

Evaluation metrics:
- Word Accuracy in Top-1 (ACC)
- Fuzziness in Top-1 (Mean F-score)

Dataset - [Link](https://huggingface.co/datasets/ai4bharat/Aksharantar)
